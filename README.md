### ⚡ Engineering Philosophy & Overview

I design, build, and secure production-grade web applications and distributed systems. My work bridges the gap between **high-performance backend architecture** (`ASP.NET Core`, `Django`), **interactive modern frontends** (`React`, `JavaScript`), and **hardened infrastructure** (`Docker`, `SQL Server`, `CI/CD`).
